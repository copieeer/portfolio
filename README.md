# Yertay — Personal Portfolio + Three Interactive Demos

A static, mobile-responsive portfolio with real browser-based demonstration projects. **These are practice projects, not paid client work.**

## Run
Open `index.html` in a browser. No installation, backend, build step, account, or API key is required.

## Pages
- `index.html` — Yertay’s portfolio, skills, project previews, contact details
- `projects/cafe.html` — café menu, category filtering, sample order summary
- `projects/dashboard.html` — tasks, completion progress, filtering, localStorage persistence
- `projects/store.html` — product search, category filters, demo shopping cart

## Free publishing on GitHub Pages
1. In the repository: Settings → Pages → Build and deployment → Deploy from a branch; select `main` and `/(root)`; Save.
2. Portfolio URL: https://copieeer.github.io/portfolio/ after GitHub Pages deploys.

## Notes
- Cafe and store carts are frontend-only demos; there is no payment processing or server.
- Dashboard stores task data only in the visitor’s browser.
- Project cards are clearly labeled as demos, and the portfolio does not claim prior paid projects.
